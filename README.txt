DripFall - Fabric 1.21.4
Budowanie:
  1. Skopiuj gradlew, gradlew.bat i folder gradle/ z https://fabricmc.net/develop/template/ (lub: gradle wrapper --gradle-version 8.12)
  2. ./gradlew build
  3. Gotowy jar: build/libs/dripfall-1.0.0.jar -> do folderu mods (wymaga Fabric API)
Test w grze: ./gradlew runClient
